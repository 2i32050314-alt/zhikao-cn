天津市 护士执业资格 报考条件

准入类-专业技术人员 ｜ 主管单位：国家卫生健康委员会、人力资源社会保障部 ｜ 公告发布：2025-12-01
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历【待核】（公告表述为“凡符合原卫生部、人力资源社会保障部印发的《护士执业资格考试办法》（部长令第74号）中报名条件的人员，可以报名参加考试”，未在本公告内重述学历条款）
专业【待核】（同上，本公告未列专业条款）
工作年限【待核】（同上，本公告未列工作年限条款）
属地毕业无工作单位考生请选择“户籍所在区考点”或“居住地所在区考点”进行报名确认；报名点按《天津考区线上确认机构一览表（护士执业资格考试）》对应选择
社保公告未涉及社保要求（报名条件与材料条款中均无社保表述）

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 《2026年护士执业资格考试报名申请表》 学校（应届毕业生）或单位、人事档案存放机构（非应届毕业生）审查盖章 【待核】 考生本人签字确认并填写联系方式后上传报名系统，原件按单位要求上交或个人留存
2 《2026年护士执业资格考试考生报名材料真实性承诺书》 所在医疗机构人事部门或存档机构审查盖章 【待核】 考生本人签字、填写联系方式，盖章后上传系统（附件1）
3 毕业证书及学历认证报告 【待核】 【待核】 按要求上传报名系统

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名2025年12月9日至12月22日，登录国家卫生健康委人才交流服务中心官网（www.21wecan.com）网上预报名
审核报名点线上审核确认：2025年12月10日至12月24日（不含节假日）；报名地市（考点）审核：2025年12月25日至2026年1月4日（不含节假日）；考区复审：2026年1月5日至1月30日（不含节假日）
缴费2026年2月4日至2月13日登录国家卫生人才网报名系统网上缴费，逾期不再补缴
准考证2026年4月1日至4月12日登录国家卫生人才网自行下载、打印准考证

四、最容易卡住的环节

  • 考生逾期未提交报名信息（未上传相关材料）或未按要求提交补充信息（未上传补充材料）的，视为主动放弃考试
  • 规定时间内未缴费的考生视为主动放弃考试
  • 发现提供虚假材料报名或考试中违规违纪的，按《专业技术人员资格考试违纪违规行为处理规定》（人社部令第31号）处理
