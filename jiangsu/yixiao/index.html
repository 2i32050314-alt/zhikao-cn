江苏省 一级注册消防工程师 报考条件

准入类-专业技术人员 ｜ 主管单位：应急管理部、人力资源社会保障部 ｜ 公告发布：2026-07-30
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历消防工程专业大专、本科（学士）、含消防工程专业的双学士或研究生班、硕士、博士；消防工程相关专业同层次；其他专业相应学历或学位亦可（年限再加1年）。学历学位须为国家承认的国民教育系列（普通高等教育、成人高等教育、电大开放教育、网络远程教育、自学考试等）。
专业消防工程专业、消防工程相关专业；相关专业审核参照附件2《消防工程相关专业新旧对照表》（含电气工程及其自动化、电子信息工程、通信工程、计算机科学与技术、建筑学、城市规划、土木工程、建筑环境与设备工程、给水排水工程、安全工程、化学工程与工艺、管理科学、工业工程、工程管理等）。
工作年限消防工程专业：大专工作满6年（消防技术工作满4年）、本科满4年（满3年）、双学士/研究生班满3年（满2年）、硕士满2年（满1年）、博士从事消防技术工作满1年；相关专业各档年限 +1 年；其他专业在此基础上再 +1 年。年限为取得学历前后本专业工作时间总和，截至2026年12月31日。
属地【待核】
社保【待核】

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名2026年8月25日9∶00—9月14日16∶00；全国专业技术人员资格考试报名服务平台（http://zg.cpta.com.cn/examfront）
审核考前抽查：报名期间由考试机构抽查；考后审查：2027年1月下旬中国人事考试网公布成绩，2027年2月上旬在江苏人事考试网发布审查公告（附件1：2027年2月上旬资格审查）
缴费8月25日—9月16日
准考证11月2日—6日，登录中国人事考试网“打印准考证”栏目下载打印

四、最容易卡住的环节

  • 考前抽查结果不通过的报考人员不可进行缴费操作（抽查结果无误方可缴费）。
  • 审查部门对报考资格存疑的审查对象，须在规定时限登录江苏省人社厅网上办事大厅上传补充证明材料，逾期未上传的视为放弃审查资格。
  • 报考人员不符合报考条件的，或者未按照资格审查要求办理报考相关事项的，按考试报名无效或者考试成绩无效处理，已缴考务费用不予退还。
