山东省 中小学教师资格（笔试） 报考条件

准入类-专业技术人员 ｜ 主管单位：教育部（江苏实施：江苏省教育厅、江苏省教育考试院） ｜ 公告发布：2026-06-23
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历报考幼儿园、小学教师资格，应当具备大学专科及以上学历；报考初级中学、高级中学、中等职业学校文化课、中等职业学校专业课教师资格，应当具备大学本科及以上学历；报考中等职业学校实习指导教师资格，应当具备中等职业学校（含技工学校）毕业及以上学历，并应当具有相当助理工程师及以上专业技术职务或者中级及以上工人技术等级。普通高等学校全日制在读3年级及以上专科、本科学生和全日制在读专升本本科生、研究生可报考；初中入学的“3+4”本科生、“三二连读”和“五年一贯制”专科生的年级按转段高等教育后（即注册高等教育学籍后）起算，其他在读生不能报考
专业“报考中等职业学校专业课、中等职业学校实习指导类别教师资格的考生，教师资格认定时申请的任教学科应与所学专业或所从事专业（有相应的职业资格或技能证书）一致。考生在报考前应详细了解本人拟申请认定教师资格所在地的认定条件。”
工作年限【待核】
属地未达到国家法定退休年龄，户籍所在地或就读学校所在地（限普通高等学校全日制在校生）或居住证申领地在山东省的中国公民，可以在我省报考。考生须选择户籍或就读学校或居住证申领地所在的考区为应试考区；持有港澳台居民居住证的应选择居住地所在的考区为应试考区；持有港澳居民来往内地通行证或台湾居民来往大陆通行证的可选择学习、工作或居住地所在的考区为应试考区
社保公告未提及社保要求

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 报名信息（个人注册及个人信息填报） 【待核】 【待核】 登录教育部教育考试院中小学教师资格考试官网报名系统注册填报；每个身份证号、手机号只能注册一次，注册时接收短信进行验证；在校生“当前年级”以本年度9月份入学后的年级为准；报名信息一经通过确认不得更改
2 本人证件照 【待核】 【待核】 上传近6个月以内免冠、正面、彩色、白底证件照，显示头部和肩的上部，不允许戴帽子、头巾、发带、墨镜；JPG/JPEG格式，不大于200K
3 现场确认材料（限反馈结果要求现场确认的考生） 【待核】 【待核】 联系考区所在市教育招生考试机构（咨询电话见附件1），按各市要求进行现场确认（公告未列明具体材料清单）

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名报名须本人通过教育部教育考试院中小学教师资格考试官网（https://ntce.neea.edu.cn/）网上报名系统进行，严禁委托他人代报。信息填报时间：2026年7月3日10:00至7月6日16:00，时间截止后报名系统自动关闭，不再受理考生报考
审核信息确认时间：2026年7月4日10:00至7月7日16:00。考生提交报名信息后须于信息确认工作截止时间前重新登录报名系统查看各市教育招生考试机构确认结果；确认未通过的，须于确认工作截止时间前修正信息并按流程重新提交，重新接受考区确认，否则为无效报名，逾期视为自动放弃；如反馈结果要求现场确认，按各市要求办理
缴费网上缴费截止时间：2026年7月8日24:00。信息确认通过后按报名系统提示网上缴费，收费标准为每人每科次60元；缴费成功后显示“报名成功（已缴费）”状态，报名全部完成；考试费一旦缴纳，概不退费；未通过确认或确认通过但未在截止日期前完成缴费，则报名不成功，按自动放弃处理，逾期不再补办
准考证报名缴费成功的考生可于2026年9月7日至9月12日登录报名系统，自行下载并打印准考证，按照准考证规定的时间、地点参加考试（考试时间见附件2）

四、最容易卡住的环节

  • 丧失教师资格人员，不得报名参加考试；受到剥夺政治权利或故意犯罪受到有期徒刑以上刑事处罚的人员，不得报名参加考试；被撤销教师资格人员，5年内不得报名参加考试；参加教师资格考试有作弊行为的，3年内不得再次报名参加考试
  • 不符合学历条件，或属于“其他在读生”（不符合在校生报考口径）的不能报考
  • 考生应自行确定是否符合报考资格，据实、准确、诚信提交报考信息，不符合的不能报考；如违反上述要求，责任由考生本人承担
  • 报名信息一经通过确认不得更改，错填信息由本人承担责任
  • 确认未通过后未按报名流程重新选择报考类别、考区、报考科目并提交重审的，为无效报名，逾期视为自动放弃
  • 未通过确认或确认通过但未在截止日期前完成缴费的，报名不成功，按自动放弃处理，逾期不再补办；考试费一旦缴纳概不退费
  • 考试违纪的取消该科目考试成绩；作弊的本次报名参加考试的各科成绩无效，3年内不得再次参加教师资格考试；构成犯罪的依法追究刑事责任
