山东省 一级注册消防工程师 报考条件

准入类-专业技术人员 ｜ 主管单位：应急管理部、人力资源社会保障部 ｜ 公告发布：2026-08-11
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历消防工程/消防工程相关专业（公告所附专业目录）的大学专科、本科、双学士或研究生班、硕士、博士学历学位均可报考，年限按学历档次递减；取得其他专业相应学历或者学位的人员，工作年限和消防安全技术工作年限均相应增加1年
专业消防工程专业；消防工程相关专业（见公告附件专业目录）；其他专业（双年限各加1年）
工作年限专科：工作满6年且从事消防安全技术工作满4年（消防工程相关专业7年/5年）；本科或学位：4年/3年（相关专业5年/4年）；含消防工程在内双学士学位或研究生班毕业：3年/2年（相关专业4年/3年）；硕士：2年/1年（相关专业3年/2年）；博士：1年（相关专业2年）；取得其他专业相应学历学位的，工作年限和从事消防安全技术工作年限均相应增加1年。工作年限、从事消防安全技术工作年限可累计，计算截止日期为考试当年度。免一科（级别为免一科，免试《消防安全技术实务》，只考综合能力和案例分析2科，须连续2个考试年度内通过）：2011年12月31日前评聘高级工程师技术职务的，或通过全国统一考试取得一级注册建筑师、勘察设计各专业注册工程师资格证书的
属地应试人员应在工作地、居住地所在市报名参加考试（资格核查、合格证书发放均由该市人事考试机构负责）
社保公告未把社保列为报考门槛（属地口径为工作地、居住地所在市）

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 《专业技术人员职业资格考试报名证明事项告知承诺制告知承诺书》电子文本 本人签署（提交） 【待核】 在线签署提交，可下载保存
2 学历（学位）在线验证/认证报告（学信网PDF报告） 中国高等教育学生信息网（学信网） 【待核】 境内高等教育学历学位信息无法在线自动核验时，报名期间按要求上传，接受网上人工核查
3 专业工作年限证明等相关材料（限特定情形现场核查） 【待核】 【待核】 免一科、不采用/撤回告知承诺制等情形须上传材料，按规定时间到各市人事考试机构规定核查点接受现场核查，通过后方可缴费

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名报名时间：2026年8月24日9∶00—9月3日16∶00
审核资格核查工作由各市人事考试机构负责，截止时间统一定于9月7日16:00
缴费缴费时间：2026年9月8日9∶00—9月14日16∶00
准考证应试人员须在2026年11月3日9∶00至11月8日18∶00期间登录中国人事考试网打印准考证

四、最容易卡住的环节

  • 不采用告知承诺制方式或撤回承诺申请的应试人员，本年度该项考试中不再适用告知承诺制，一经选择无法更改
  • 缴费成功前须通过资格核查；核查不通过情形下无法缴费（公告核查程序规定核查通过后方可进行缴费）
