河南省 二级建造师 报考条件

准入类-专业技术人员 ｜ 主管单位：住房和城乡建设部、人力资源社会保障部（江苏实施：江苏省住房和城乡建设厅、江苏省人力资源和社会保障厅） ｜ 公告发布：2026-03-19
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历具备工程类或工程经济类中专及以上学历；或具备非工程类、非工程经济类中专及以上学历并取得工程类中级及以上专业技术资格（考全科）
专业工程类或工程经济类专业；非工程类或工程经济类中专及以上学历报考须取得工程类中级及以上专业技术资格；专业审核参照《建造师执业资格考试实施办法》（国人部发〔2004〕16号）和2022年版《一级建造师资格考试专业对照表》
工作年限工程类或工程经济类中专及以上学历须从事建设工程项目施工管理工作满2年；免一科：具有工程类中级及以上职称且从事建设项目施工管理工作满15年；工作年限计算截至2026年12月31日
属地原则上选择工作单位注册地报名，一般不跨市、跨单位报名考试；省直和中央驻郑副厅级以上单位考生考区选“省直”，省辖市考生选相应省辖市
社保【待核】

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 电子证件照片 【待核】 【待核】 单色背景（红、蓝或白）正面免冠近期1寸或2寸证件照，JPG/JPEG，字节大于30KB，宽高像素大于220*300，须用照片处理工具处理
2 资格考试报名表 【待核】 一式两份 A4纸打印，本人留存以备考试合格后核查
3 专业技术人员资格考试报名证明事项告知承诺制报考承诺书 【待核】 【待核】 网上电子签署，未签署无法缴费

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名网上报名时间：2026年3月20日9：00至3月24日17：00
审核考后资格核查：考试合格标准发布后，省、市住建部门对成绩合格人员承诺事项进行报名资格核查（公告未列核查起止日期，见省、市住建部门及省人事考试中心核查通知）
缴费网上缴费时间：2026年3月21日9：00至3月25日17：00，逾期不予补缴
准考证准考证打印时间：2026年5月26日9：00至5月31日17：00

四、最容易卡住的环节

  • 资格核查部门发现考生不符合报考条件的，取得考试成绩的当次全部科目成绩无效；取得证书的资格证书无效
  • 由于被核查人原因造成无法在规定期限内完成核查的，视为自动放弃考试资格和本次考试成绩
  • 提供虚假证明材料等严重违纪违规行为，按人社部令第31号第十条、第十二条处理
